📤 Publishing Workflow (Export → Upload)

  1. Click "Download games-data.js" below to export your finalized platform configuration.
  2. Open your hosting provider's File Manager or FTP client (e.g. Netlify, Vercel, Hostinger).
  3. Replace the existing js/games-data.js file in the `js/` directory with your newly downloaded file.
  4. Reload your live website to see all updates take effect immediately!

🚀 Deployment & Hosting

  1. Free Global CDN Deployment: Deploy effortlessly on Vercel or Netlify. Drag-and-drop the root folder for instant global HTTPS hosting with 99.99% uptime.
  2. Custom Domain: Connect your custom `.com` or `.io` domain in your hosting dashboard under Domain Settings.
  3. Zero Database Requirement: The entire arcade runs statically with client-side state, meaning zero server maintenance and blazing fast speed worldwide.
