🚀 1. Site Live Korar Steps (Code Na Janle O)

  1. Free hosting nichhen: Netlify-e janun → Sign up (GitHub ba email diye) → "Add new site" → "Deploy manually" → pura Game_Version_1 folder drag-drop korun. 1 minute-e site ready, URL paben.
  2. Domain: Netlify free subdomain diye shuru korun (jemon khairplay.netlify.app). Pore custom domain (jemon khairplay.com) Netlify thekei nite parben — dorkar nai ekhono.
  3. Folder structure intact rakhben: index.html folder-r root-e, games/ pages/ css/ js/ admin/ — kichu rename/sorryben na.
  4. Update: kono kichu bodlate Control Panel-e edit → Export → file manager-e replace. Done.

💰 2. AdSense Approve Howar Checklist

Google 100% manush dekhei approve dey — checklist follow korle chance onek beshi:

📄 3. ads.txt Content

Apnar real Client ID pele button-e click kore copy kore root-e ads.txt file-e paste korun:

google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0

Netlify-e: Site settings → "Build & deploy" → "Post-processing" → "Ad inventory declarations" jodi na thake, ekta notun file banan nam ads.txt folder-r root-e (index.html er sathe) — Netlify auto root-e serve kore.

📈 4. Income Baranor Upay

  • 🔹 Ad placement: ekhon placement balanced — top banner (home), mid (home/games), bottom (play page game-er niche). Eta user-ke birokti korbe na, ar view o beshi hobe.
  • 🔹 Content baran: proti saptaho 1-2 notun game add korun — Google index-e notun page hole organic traffic ashe.
  • 🔹 SEO: title/description unique rakhben — game er description apnar style-e likhun.
  • 🔹 Social: Facebook page / YouTube Shorts-e gameplay clip baniye link dicchen — bacchhader jonno kids games khub viral hoy.
  • 🔹 Ad balance: kono ad slot-e ekshathe 1-2 beshi ad dhorben na — auto ads On kore rakhteo parben AdSense theke (Settings-e ki korchi seta apni decide).

🔐 5. Security Note

Ei panel-er password file-e ache (browser-e kaj kore) — mane technically jani tara HTML theke password dekhte pare. Tai:

  • 🔹 Panel link footer-e ache, kintu Google-e index hocche na (noindex) — search-e ashbe na.
  • 🔹 Beshi risk nai — panel kintu kono data server-e rakhe na; shob kichhu apnar browser-e.
  • 🔹 Jodi apni boro site korben, hosting-er Password Protection (Hostinger cPanel-e "Directory Privacy", Netlify-e password-protected deploy) chara parben extra layer hisebe.
  • 🔹 Password regularly bodolen, strong rakhen.

🆘 6. Kono Samossa Hole

  • 🔹 Site blank? → File manager-e check korun js/games-data.js ache ki.
  • 🔹 Draft dekhacche kintu live hoyna? → Export/Import tab-e ashen, file download kore replace bhulo to na?
  • 🔹 Ad nei? → Client ID + Slot ID diye disen ki check korun, ar ads.txt root-e ache ki.
  • 🔹 Game kaj kortese na? → Games tab-e Preview click kore dekhun, ar file path thik ache ki (games/ folder-e HTML file ache ki).
